# Probability for data scientists

Probability measures how likely an event is, on a scale from 0 to 1. The lesson starts from counting outcomes, so a comfortable grasp of fractions and basic algebra is all you need.

We cover independent events, conditional probability and Bayes' theorem, and use them to reason about a medical test with false positives. Random variables, expected value and variance come next, followed by the most common distributions: the binomial and the normal distribution.

These ideas are the basis of statistics: confidence intervals and hypothesis tests are all built on probability.
