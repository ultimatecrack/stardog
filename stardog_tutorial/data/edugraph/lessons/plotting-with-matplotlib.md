# Plotting with matplotlib

Good charts make patterns visible. This lesson uses matplotlib, the most widely used Python plotting library, together with the plotting shortcuts built into pandas.

You should know how to load and filter data with pandas DataFrames. We draw line charts, bar charts, histograms and scatter plots, label axes, and add titles and legends. Then we combine several charts into one figure with subplots.

We finish with advice on choosing the right chart for the question, and on colour: use a sequential palette for ordered values and avoid red-green contrasts, which many people cannot tell apart.
