# Stardog with Python: Tutorial

A hands-on tutorial from knowledge graph basics to GraphRAG and agents, using **pystardog** against **Stardog Cloud**. Full plan: [CURRICULUM.md](CURRICULUM.md).

## Getting started

1. Create a `.env` file in the **project root** (one level up), based on [00_setup/.env.example](00_setup/.env.example).
   Check it with `.venv\Scripts\python stardog_tutorial\00_setup\check_setup.py` (run from the project root). All five checks should pass.
2. Open a notebook in `notebooks/` and select the project's `.venv` as the kernel (VS Code: *Select Kernel → Python Environments → .venv*).
3. Run the cells in order.

Each chapter writes only to its own named graphs (`urn:tutorial:chNN:*`) and removes them at the end, so chapters never interfere with each other or with other data in your database.

## Folders

| Folder | Contents |
|---|---|
| `00_setup/` | `.env.example`, `check_setup.py` |
| `data/` | Datasets, one folder each: `company/` (Ch 1-2), `recipes/` (Ch 3-9: source CSVs in `csv/`, `recipes.ttl` generated by Ch 3, `ratings.nt.gz` generated by Ch 5), later `edugraph/`, … |
| `notebooks/` | One notebook per chapter |
| `src/kg/` | Reusable Python code: `client.py` (connections, transactions, error advice, setup check), `sparql.py` (`run_query()` and friends), `recipes.py` (IRI conventions, recipe → RDF), `updates.py` (idempotent upsert) |
| `src/kg/queries/` | SPARQL queries as `.rq` files, one folder per topic (`recipes/`, …) |
